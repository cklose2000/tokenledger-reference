# Changelog

## v0.2.0-rc.6 (candidate, 2026-09-10)

Adds the reporting-learning loop as a credential-free synthetic walkthrough,
`tl learning walkthrough`, with a retained recording, a relocated offline
replay (`tl learning replay-walkthrough`) and a reader page, `docs/learning.md`.
The walkthrough runs the real gateway, admission validator, bounded candidate,
scalar oracle and receipt engine against an in-memory stream and DuckDB with a
disposable synthetic signer. Its gateway configuration is marked synthetic and
cannot be served or used by cloud commands.

Renames the reader exercise's route from "learning" to "workflow" so the two
meanings stay apart. Carries the engine's `sqlglot` core dependency. Reports the
one actual signed native trial as inconclusive with no promotion; that result
is retained, not improved. Publication remains a separate approval.

## v0.2.0-rc.5 (candidate, 2026-09-08)

Carries forward the public-only history and native reporting runtime. Adds an
optional offline verifier for retained cloud populations, with shared receipts,
the measured resource trade-off and the earlier failed tenfold hypothesis.
Reorganizes the reader path around the demo, Run / Understand / Assess, and a
standalone architecture export. See `release-status.json` for actual acceptance
and publication state.

Incorporates two agents' usability reviews and returning checks: clearer
adoption boundaries, a receipt-derived summary beside the recording, an
ordinary-interface challenge guide and repaired offscreen node selection.
The final field clarifications preserve the executable and grading contract.
